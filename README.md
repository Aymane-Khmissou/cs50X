## About

CS50x is Harvard's introduction to the intellectual enterprises of computer science and the art of programming, taught by David J. Malan. I completed the full course, including **ten problem sets and a final project**, and earned the official certificate shown above (you can verify it with the badge).

This repository is a summary of what I learned. It intentionally contains no problem set code, in line with the course's academic honesty policy.

## 11 weeks at a glance

| Week | Topic | What I learned |
|:----:|-------|----------------|
| 0 | **Scratch** | Computational thinking: functions, loops, conditions, events and threads, and how to break a problem into small steps. |
| 1 | **C** | My first text-based language: compiling, variables, types, loops, and how source code becomes a running program. |
| 2 | **Arrays** | Strings as arrays, command-line arguments, and cryptography basics. Writing readable, well-structured code. |
| 3 | **Algorithms** | Linear and binary search, bubble, selection and merge sort, recursion, and Big O notation for comparing efficiency. |
| 4 | **Memory** | Pointers, `malloc` and `free`, the stack and heap, file I/O, and debugging memory errors with Valgrind. |
| 5 | **Data Structures** | Linked lists, hash tables, tries, stacks and queues. Choosing the right structure for speed versus memory. |
| 6 | **Python** | A high-level language: libraries, dictionaries, file handling, and how much faster development gets compared with C. |
| 7 | **SQL** | Relational databases: `SELECT`, `JOIN`, `INSERT`, `UPDATE`, indexes, and designing tables with keys. |
| 8 | **HTML, CSS & JavaScript** | Building web pages: structure, styling, responsive layout, DOM manipulation, and client-side interactivity. |
| 9 | **Flask** | Full-stack web apps: routing, templates, sessions, forms, database integration, and the request/response cycle. |
| 10 | **Final Project** | Designing, building and presenting an original project from scratch, applying everything from the course. |

## Skills gained

- **Languages:** C, Python, SQL, HTML, CSS, JavaScript
- **Tools:** Git and GitHub, the command line, Flask, SQLite, Valgrind, `make`
- **Computer science:** algorithms and complexity, data structures, memory management, databases, web development
- **Habits:** debugging methodically, reading documentation, writing clean code, and testing with `check50` and `style50`

## What CS50 taught me

- **Problem solving matters more than syntax.** Languages change; breaking a problem down and reasoning about it carries over everywhere.
- **Understanding low-level details makes you better at high-level work.** Working in C with memory and pointers made me appreciate what Python and the web frameworks do behind the scenes.
- **Efficiency is a design choice.** Comparing algorithms and data structures changed how I think about writing code that scales.
- **Debugging is a skill to practise.** Rubber-duck debugging, `printf`, and reading error messages carefully saved me hours.
- **Persistence works.** Some problem sets took many attempts, and finishing them taught me more than the easy ones.
